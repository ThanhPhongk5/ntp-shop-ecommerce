# NTP Shop - E-commerce Web Application

NTP Shop is a simple e-commerce web application built with Spring Boot.  
The system allows users to browse products, add items to cart, and provides an admin panel to manage products.

## Tech Stack

Backend
- Java
- Spring Boot
- Spring Data JPA
- MySQL

Frontend
- HTML
- CSS
- JavaScript

Tools
- Git
- Maven

## Features

User
- View product list
- View product details
- Add products to cart

Admin
- Create, update, delete products
- Upload product images
- Manage product information

Backend
- RESTful API with Spring Boot
- CRUD operations
- Image upload and static resource handling
- Layered architecture (Controller, Service, Repository)
